# Subject Interface Specification

```python
class SubjectIntelligencePack(ABC):
    subject: SubjectId
    version: str

    def capabilities(self) -> list[SubjectCapability]: ...
    def analyse_lesson(self, uli, context=None) -> SubjectAnalysisResult: ...
    def build_concept_graph(self, uli, context=None) -> dict: ...
    def detect_misconceptions(self, uli, context=None) -> list[dict]: ...
    def recommend_visuals(self, uli, context=None) -> list[dict]: ...
    def recommend_interactions(self, uli, context=None) -> list[dict]: ...
    def build_assessment_hints(self, uli, context=None) -> list[dict]: ...
    def build_revision_summary(self, uli, context=None) -> dict: ...
    def build_accessibility_guidance(self, uli, context=None) -> list[dict]: ...
    def build_tutor_guidance(self, uli, context=None) -> list[dict]: ...
    def build_lxp_hints(self, uli, context=None) -> list[dict]: ...
```

`SubjectAnalysisResult` fields: concept_graph, misconceptions, visuals, interactions,
assessment_hints, revision_summary, accessibility_guidance, teaching_strategies,
tutor_guidance, lxp_hints, warnings, metadata, placeholder.

Default method implementations delegate to `analyse_lesson()`.
