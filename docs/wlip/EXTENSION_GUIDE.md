# WLIP Extension Guide

1. Reuse SICS builders for taxonomy, misconceptions, pedagogy, diagrams, assessment, accessibility, tutor, analytics.
2. Add skill foci in domain modules under `engines/world_languages_intelligence/`.
3. Add languages with `register_language_plugin()` — no engine API changes.
4. Keep English subject ownership on ELIP; mark new L1/L2 English references `integration_only` if needed.
5. Additive ULIQE seeds only (`ULIQE.WLIP.*`); never change certification thresholds.
6. LXP owns rendering for IPA, recorder, popups, and translation drawer.
