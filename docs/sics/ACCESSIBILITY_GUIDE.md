# Accessibility Guide (SICS)

`build_accessibility_guidance(recommendations, uli, attach_reading_band_to=...)`

## Shared utilities

- Normalize recommendation rows (`recommendation`, `detail`, `owner`)
- Optionally attach ULI reading band to a named recommendation

## Ownership

- **SICS** — metadata shaping only  
- **AIE** — learner profile adaptation and UI application  
- **VMLE** — read-aloud / multimodal delivery  

Do not duplicate AIE sensory profiles or readability engines inside subject packs.
