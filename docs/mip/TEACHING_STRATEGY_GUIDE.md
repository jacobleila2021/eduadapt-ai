# Mathematics Teaching Strategy Guide

MIP recommends verified pedagogical frameworks as **metadata**. Lesson content remains the verified ULI / curriculum source.

## Supported frameworks

| Framework | Classroom intent |
|-----------|------------------|
| Concrete–Representational–Abstract (CRA) | Sequence manipulatives → diagrams → symbols |
| Explicit Instruction | Model → guided practice → independent |
| Gradual Release of Responsibility | I do → We do → You do |
| Productive Struggle | Allow justified effort before full scaffold |
| Retrieval Practice | Low-stakes recall of lesson rules |
| Interleaving | Mix related problem types |
| Spaced Practice | Revisit at 1 / 3 / 7 day intervals |
| Multiple Representations | Verbal, tabular, graphical, symbolic |

## Domain-aware visuals (recommendations only)

Rendering is owned by LXP / VMLE. MIP recommends types such as:

- Number lines, bar models, fraction models, place-value charts
- Algebra tiles, balance scales, coordinate planes, function plots
- Geometry constructions, angle diagrams, nets
- Unit circle, right-triangle diagrams
- Histograms, box plots, scatter plots
- Probability trees, Venn diagrams

## Worked-example scaffolds

Each scaffold includes: goal, given (from source claim), step prompts, justification prompt, common mistakes, extension challenge.

When `exam_mode` / `protected_assessment` is set in SIF context, **final verification text is omitted** so answers are not leaked.

## Instructional sequence (default)

1. Activate prerequisites from concept graph edges  
2. Concrete / representational hook (recommended visual)  
3. Explicit model of one source-linked example  
4. Guided fading via ATIE graduated hints  
5. Independent practice (AME items)  
6. Misconception check + retrieval exit ticket  
7. Spaced revision metadata for LMAS/ALE
