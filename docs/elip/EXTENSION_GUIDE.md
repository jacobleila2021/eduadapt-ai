# ELIP Extension Guide

ELIP is the reference **non-STEM** pack for Social Science, CS, Commerce, and World Languages.

1. Reuse SICS builders (`detect_from_catalogue`, `build_teaching_strategies`, taxonomy, assessment, accessibility, tutor blocks).  
2. Keep subject catalogues pack-local.  
3. Register via SIF `_ensure_production_packs`.  
4. Add additive ULIQE stage/seeds only — never change certify thresholds.  
5. Metadata for ATIE/AIE/AME/LAIE/ALCIS/LXP/VMLE — never replace those engines.
