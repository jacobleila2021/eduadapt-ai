# English Language Intelligence Architecture

**Pack:** English Language Intelligence Pack (ELIP)  
**Version:** 1.0.0  
**Smoke:** `ENGLISH_LANGUAGE_INTELLIGENCE_SMOKE_OK`

## Role

ELIP is Alora AI’s first **non-STEM** production Subject Intelligence Pack. It is a curriculum-aware **literacy and language intelligence layer** for reading, vocabulary, grammar, writing, literature, speaking, and listening — not a grammar checker and not a generic LLM wrapper.

Built on **SIF + SICS**. Enriches verified ULI lessons with metadata for ATIE, AIE, AME, LAIE, ALCIS, VMLE, and LXP.

## Guarantees

- Never invents curriculum or unsupported literary claims  
- Never auto-generates assessment answers  
- Never changes ULIQE certification thresholds (`ULIQE.ENG.ELIP.*` additive)  
- Reuses AIE/AME/ATIE/VMLE/LAIE/ALCIS/LXP — does not replace them  

## Package

`engines/english_language_intelligence/` — reading, vocabulary, grammar, writing, literature, speaking, listening, pronunciation, pedagogy, assessment, accessibility, analytics, validation, competencies, pack/service/engine.
