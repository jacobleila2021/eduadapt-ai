# Physics Scientific Teaching Guide

PIP recommends verified scientific teaching frameworks as **metadata**. Curriculum remains the ULI / Knowledge Layer source of truth.

## Frameworks

| Framework | Intent |
|-----------|--------|
| Inquiry-Based Learning | Question-driven investigation of lesson phenomena |
| Predict–Observe–Explain (POE) | Elicit prediction, confront observation, revise model |
| Claim–Evidence–Reasoning (CER) | Structure scientific explanations |
| CRA | Apparatus → diagrams/graphs → formulae |
| Guided Discovery | Scaffolded path to the lesson principle |
| Experimental Investigation | Variables, method, data, conclusion |
| Conceptual Change | Confront and repair misconceptions |
| Retrieval Practice | Low-stakes recall of laws and models |
| Visual Learning | Force/ray/circuit/wave diagrams first |

## Recommended visuals (LXP/VMLE render)

Force diagrams, motion graphs, ray diagrams, circuit diagrams, wave diagrams, energy flow diagrams, field diagrams, vector diagrams, experimental apparatus, interactive simulations.

## Default instructional sequence

1. Activate prerequisites from the concept graph  
2. Concrete demo / apparatus (if in source)  
3. POE or diagram modelling  
4. Explicit link to lesson formula/principle  
5. Worked-example fading via ATIE  
6. Misconception check + CER exit ticket  
7. Spaced revision metadata for LMAS/ALE
