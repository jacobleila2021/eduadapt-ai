# SSIP Extension Guide

SSIP is the reference humanities pack; CSIP (`docs/csip/`) covers technology;
CEIP (`docs/ceip/`) covers commerce. Next: WLIP.

1. Reuse SICS builders.  
2. Keep domain catalogues pack-local.  
3. Register related subject keys via a family registrar when one pack covers multiple SIF subjects.  
4. Additive ULIQE seeds only.  
5. LXP owns timelines/maps rendering; SSIP owns metadata.
6. The `economics` subject key is owned by CEIP; school economics markers still enrich under `social_science`.
